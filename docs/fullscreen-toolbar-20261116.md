# 全屏工具条（0.3.0-rc.9）

RDP、VNC、SPICE 和 Android 浏览器全屏共用 `FullscreenToolbarShell`。
默认不固定：进入全屏后显示约 2 秒；鼠标在顶部中央把手停留 200ms，或触摸点击把手可展开；离开工具条约 1 秒后收起。
固定偏好保存在 `uniterm:fullscreen-toolbar-pinned:v1`，适用于后续全屏会话。用户可点击收起按钮取消固定并返回远程画面。

把手的命中区域是顶部中央 64×44px，实际可见部分 48×18px，没有横跨全屏的透明拦截层。
工具条使用绝对定位覆盖画面；展开和收起不改变远程画布大小。隐藏内容设置 inert，不进入键盘焦点序列。
输入框、键盘导航、展开的菜单，以及 RDP 键盘/文件面板、VNC 区域编辑器和 Android 功能面板会保持工具条展开。
远程鼠标或触摸拖拽期间，工具条和把手让出命中区域，避免截断释放事件。工具条本地操作释放远程输入捕获并阻止事件向远程视图冒泡。
退出全屏按钮有明确标签；没有增加占用远程按键的快捷键。

Android 普通窗口仍使用底部栏，画中画和独立窗口仍使用原有侧栏；进入浏览器全屏时使用共用顶部工具条。
全屏状态按根元素实际所属的 document 跟踪，Teleport 移动后重新绑定，恢复窗口和卸载时清理监听。

插件版本统一读取 `router-plugin/package/uniterm/version`。前端和服务端版本包含 Git 提交前八位；安装器同步软件中心版本，避免继续显示旧 rc.3。
本次沿用已部署的 `0.5.1-uniterm.17` 图形协议包，不改变视频解码、绘制或音频调度。
