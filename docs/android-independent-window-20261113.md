# Android 独立窗口

工具栏新增「独立窗口」图标，原生画中画仍保留。点击时同步调用 window.open，以保持用户手势；被拦截时在原标签页显示允许弹窗的提示，不关闭连接。复用当前 canvas、解码器和 Android 会话，Vue Teleport 将界面移动到同源弹窗。

独立窗口沿用 44px 图标工具栏、右侧隐藏把手、边缘唤出/自动隐藏及主题同步，body padding 为 0。初始大小跟随实际视频比例。铺满按钮调整普通窗口到屏幕工作区；全屏使用内容所在文档的 API。关闭/还原弹窗把同一画布移回原标签页；主页面离开或组件销毁时关闭子窗口。普通窗口不保证系统置顶，浏览器标题栏和窗口尺寸策略仍由浏览器管理。

适应窗口模式允许视频等比例放大到大窗口，实际像素模式不放大。画布边界仍是实际画面边界，触摸坐标映射不改变。

## 测试

Xvfb 1440×1000 有界面 Chromium + redroid：
- 拦截 window.open 返回 null 后显示提示且原画面可用。
- 原生弹窗出现且 canvas 身份保持一致，无额外 Android WebSocket。
- 铺满后的 outerHeight 为 999px（screen.availHeight=1000px），innerHeight=964px，超过画中画 80% 上限。
- 独立窗口全屏/退出全屏成功。
- 普通缩放成竖向高窗口后，视频显示高度 964.96875px，内容区高度 965px，保持源画面比例 0.46。
- 窗口关闭和工具栏还原均回到原标签页，连接保持正常；全程 WebSocket 数量未增加，无 pageerror。
