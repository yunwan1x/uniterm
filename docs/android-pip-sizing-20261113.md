# Android 画中画比例与 v1.6.4

原生画中画初始尺寸跟随实际视频宽高比，竖屏在 360×690 范围内等比例计算，横屏使用 690×360 范围。使用接收到的视频尺寸而非尚未绘制的 canvas 默认 300×150，避免刚连接立即打开时方向错误。PiP body 单独设置 padding:0，不改变主窗口的 1px 桌面适配边距。状态栏和导航栏保留，未裁剪或拉伸 Android 画面。

## 实测

使用 Xvfb 中的有界面 Chromium 和真实 redroid，未用 Playwright 手动改变 PiP 尺寸：368×800 视频自动得到 317×690 内容窗口，body padding 为 0，画布左右留白为 0，上下各 0.4375 CSS px（整数窗口尺寸取整）。44px 图标工具栏覆盖显示且默认隐藏，展开/收起不改变画面尺寸；设置面板、显示模式、主题同步正常。

60 项相关前端测试通过，包含竖屏、横屏、方形比例和首帧未绘制时的尺寸选择。生产前端与 server 构建通过。截图与测量位于仓库外 ../artifacts/android-v164-20261113。

此为初始窗口比例；用户随后手动改变宽高比，或浏览器限制窗口尺寸时，等比例显示仍可能产生留白。没有强制锁定系统窗口比例。

v1.6.4 同时包含此前未发布的网页浮窗触边扩展、原生 PiP 自动隐藏图标工具栏、Android 连接错误提示和首次视频超时。
