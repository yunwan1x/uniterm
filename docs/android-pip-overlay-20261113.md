# 原生 Android 画中画覆盖工具栏

原生 Document PiP 使用完整宽度的视频区域。工具栏默认隐藏，右侧 6px 热区或小按钮可唤出，鼠标离开工具栏 250ms 后收起；按钮可固定/取消固定。键盘焦点在工具栏内时保持显示。工具栏覆盖画面，不引起视频区域缩放。设置面板使用画中画窗口可用宽度。原有网页内悬浮和普通标签页保留原工具栏布局。

Chromium 原生 Document PiP + redroid 实测（360×690）：隐藏时视频区域宽度 358px（窗口 360px，边界占 2px）；展开后区域宽度不变；边缘唤出、移开隐藏、按钮固定/收起、画质设置面板和实时主题同步通过，未出现 pageerror。截图及脚本存放在仓库外 ../artifacts/android-pip-overlay-20261113。

20 项 Android 客户端和悬浮窗测试通过，前端生产及 server production 构建通过。全量类型检查仍为 570 个既存错误，修改组件没有新增类型错误。

同工作区还包含网页悬浮窗边缘扩展修复（同属 v1.6.4）。该改动纳入 v1.6.4 发布。临时测试服务已关闭，redroid 保持运行，未修改其设备尺寸或 DPI。

## 紧凑图标工具栏

工具栏宽度缩至 44px，按钮 32×32px、图标 17px；导航、设备显示、画质、显示模式、来源、键盘、文件和 Shell 均使用图标及本地化 title tooltip/可访问名称。显示模式与来源选择移到图标打开的设置面板。360×690 原生画中画实测侧栏宽度 44px，全部操作按钮含图标、tooltip 与可访问名称且不显示文字；显示模式切换、面板布局及原有自动隐藏/固定/主题同步均通过。20 项测试和生产构建通过。截图及日志：../artifacts/android-pip-icons-20261113。
