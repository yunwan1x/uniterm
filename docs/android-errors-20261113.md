# Android 连接错误提示

- 连接失败显示有明确标题的 role=alert 卡片，包含可复制的详细原因与重连按钮。显式层级确保视频不遮挡错误，窄窗口内换行/滚动；连接进度使用 role=status。
- Wails Error/结构化 message/error/cause/字符串统一提取，未知错误显示操作建议而非 [object Object]。缺失连接配置也显示明确错误。
- 标签页同步连接/失败状态。服务器错误和解码错误终止客户端，保留原始原因；主动关闭不误报。
- 新增 45 秒首次视频超时，收到元数据但一直无视频数据也会报错；首次视频数据成功写入解码器后取消定时器。dispose 清理定时器、缓存和连接。
- 非法 JSON/元数据转为可见错误；晚到的网络/解码错误不会覆盖已终止会话的原始错误。

## 验证

27 项客户端、错误提取及悬浮窗测试通过，前端生产构建通过。全量类型检查保留既存 570 个错误，修改组件与 Android 客户端没有新增错误。

Chromium 浏览器实测：真实 127.0.0.1:1 连接拒绝显示后端详细原因，卡片处于最上层，重试后保留错误。另通过浏览器截断 Android 视频 WebSocket、推进浏览器时钟验证 45 秒无视频超时，重连按钮可用；此场景是故障注入，不是模拟设备实际网络延迟。两场景无 pageerror。
